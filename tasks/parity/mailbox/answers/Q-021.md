## Decision
Superseded-by-merge: Q-022 hit the same ambiguity at the transition circuit, so the
full canonical spec lives in **answers/Q-022.md** (normative). Short answers to your
three questions:

1. **Neither plain MSB-from-leading-bit nor LSB-first.** The canonical ladder is
   MSB-first over all 256 bits from a **blinded start** `acc_0 = B = (i+1)·G` with
   public blind index `i`, followed by a correction add `⊕(−2^256·B)`. This is what
   makes the circuit uniform for every scalar (even/zero included) with no infinity
   and no active-prefix flag. WO-BL4's "LSB-first" line was an error and is corrected.
2. **The point slots hold `acc_1..acc_256`** — 256 post-step accumulators per scalar,
   not 255 (`acc_0` is public, unstored). The frozen layout is revised to LAYOUT v2
   (Q-022 §4, total 2680) — this answer is the mailbox event that layout change
   required.
3. **Denominator ordering:** family-major, then step order, interleaved
   `[λD_inv_j, λA_inv_j]` pairs — all u1G (512 + 1 correction), all u2Q (513), then
   the single final-add denominator. 1027 total; the 514 figure in G4/BL4 was wrong
   (a uniform mux'd step consumes both the double and the add denominator every step).

Determinism note for hints.rs: the blind index is part of the deterministic output —
start at `i = 0`, increment only on `ExceptionalTrace`, so same input ⇒ same index ⇒
byte-identical witness still holds.

Your parallel work (public-key parsing, final add, final reduction) is unaffected.
