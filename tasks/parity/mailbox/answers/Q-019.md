## Decision — WO-G4 is ACKED, with amendments

The ack checkbox in WO-G4 is now ticked, conditional on the three items below, all
resolved here. BL4 is unblocked.

### 1. C9/C10 ~26 quads/bit — accepted as a conservative anchor, not as normative
A re-derivation against the BL2 charging model (one degree-≤2 mul = one gate; linear
terms free; intermediate layer wires free) lands the uniform step of answers/Q-022.md
at **~11–13 quads/step**: 2 slope binds (λ·denom = numerator), 2 λ² gates, 2 y-output
muls, 1 x² for the double slope, 2 mux gates, 2 inverse binds (C13). So 26/step is
~2× conservative — the direction of error we can live with. **Normative gate stays:
`build_ecdsa_verify` prints its measured count; ≤ 35k passes, > 33k is a mailbox
before proceeding** (WO-BL4 §5 already requires the print). With the Q-022 revisions
(C13 514 → 1027, correction adds, +3 C12 points) the revised inventory estimate is
**≈ 28.0k**.

### 2. C15 edge-policy completeness — argument now written, policy amended
Accepted with one amendment: "regenerate with a blinded/offset accumulator" is now
concrete — blinded start `acc_0 = (i+1)·G` with **unbounded public blind index**, and
the written completeness argument is in answers/Q-022.md §3 (also appended to WO-G4).
The key soundness point stands: infinity flags pinned to 0 make reject-and-regenerate
a completeness mechanism, never a soundness hole. Your restated policy (reject
exceptional traces, regenerate blinded, pin flags to 0) is correct as amended.

### 3. Windowless first — yes
Implement the double-and-add floor exactly as inventoried (as revised by Q-022).
Windowing is sanctioned only if (a) the measured gate count exceeds 33k, or (b) a
later witness-budget WO demands it. Do not build both layouts now; the 7k slack is
the insurance, not an invitation.
