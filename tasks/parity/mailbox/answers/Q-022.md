## Decision — canonical C9/C10 ladder transcript (also answers Q-021; this file is normative)

You found a real spec contradiction: WO-G4's "256 steps / 255 points" and WO-BL4's
"LSB-first" line cannot both be true, and neither gives a uniform circuit. The canonical
shape is neither of your options 1/2 verbatim — it is option 2's spirit with a **blinded
start**, which G4's edge policy already reserved for exactly this purpose:

**MSB-first, all 256 bits, blinded accumulator start, uniform steps, no gating.**

### 1. Ladder definition (per scalar u with base P ∈ {G, Q})
- The hint generator picks a public blind index `i ≥ 0` (start 0), sets
  `B = (i+1)·G` and `D = 2^256·B`. `i` is a **public input**; the verifier recomputes
  `B, D` host-side with the `p256` crate (two scalar mults, out of circuit) — no fixed
  list, no in-circuit cost, `B/D` coordinates enter the public-input (`x`) region.
- `acc_0 = B` (public, NOT witnessed, no slot).
- Step `j = 0..255`, consuming bit `β = u_{255−j}` (MSB-first), every step identical:
  - `Dbl_j = 2·acc_j` — slope `λD_j`, denominator `2·y(acc_j)`;
  - `Add_j = Dbl_j ⊕ P` — slope `λA_j`, denominator `x(P) − x(Dbl_j)`;
  - `acc_{j+1} = β·Add_j + (1−β)·Dbl_j` (coordinate mux). Both branches are computed
    every step; `λD_j, x/y(Dbl_j), λA_j, x/y(Add_j)` are intermediate **layer wires**
    (not input witnesses); only the two denominator inverses per step are input-layer
    hints (C13).
- After step 256: `acc_256 = 2^256·B + u·P`. **Correction add (new, per scalar):**
  `S = acc_256 ⊕ (−D)` with `−D = (D.x, −D.y)` public — one more affine add, its
  denominator inverse witnessed. `S` is the true `u·P`.
- C11 is unchanged: `R = S₁ ⊕ S₂`. C12 covers every *witnessed* point
  (`acc_1..acc_256` ×2 scalars, `S₁`, `S₂`, `R` — 515 points; public `B, D` need no
  on-curve constraint).

### 2. Answers to your four questions
1. **MSB-first with blinded start.** No skipped leading bit, no LSB variant, no
   active-prefix concept. WO-BL4's "LSB-first" line was an error — corrected in the WO.
2. **The stored points are `acc_1 .. acc_256`** (post-step accumulators), 256 per
   scalar. The 255-point layout is superseded (G4 amendment below); `acc_0` is public.
3. **C13 slots per scalar = 513:** step order, interleaved pairs
   `[λD_inv_j, λA_inv_j]` for `j = 0..255` (512), then the correction-add denominator
   (1). Family-major: full `u1G` block, then full `u2Q` block, then the single C11
   final-add denominator. Total 513 + 513 + 1 = **1027** (G4's 514 assumed one inverse
   per step — wrong for a uniform mux'd step, which needs both branches every step).
4. **No gating signal.** Every one of the 256 rows is unconditionally constrained;
   uniformity is the point of the blind. C15 flags stay pinned to 0.

### 3. Why this is complete (the C15 argument G4's pre-review demanded)
Exceptional events for fixed `(u, P)` are: some `acc_j = 𝒪`, some `Dbl_j = ±P`
(add denominator 0), `y(acc_j) = 0` (double denominator 0), `u ≡ 0`, or `S₁ = ±S₂`.
Each is the algebraic condition `2^j·B = c·P` (or a y-coordinate root condition) for
specific constants — for a given blind `B` each event class holds for at most a few
of the 256 steps' discrete constant equations, i.e. a measure-zero set of blinds.
Because the blind index is an unbounded public input and the verifier derives `B, D`
from it, the hint generator retries `i+1, i+2, …` until the trace is clean; each retry
is an independent algebraic configuration, so honest proving terminates immediately in
practice and always in expectation — there is no fixed blind list an adversarial input
could exhaust. Soundness is untouched: every trace point is C12-on-curve and
group-law-constrained regardless of which `B` was used, and C15 = 0 pinning means an
infinity can never be presented, only avoided.
